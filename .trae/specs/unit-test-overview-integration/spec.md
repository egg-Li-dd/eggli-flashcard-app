# 单元检测界面优化 — 章节检测与检测概览整合

## Why
当前"单元检测"页面中，"📖 按章节检测"按钮是一个独立的全宽按钮，孤零零地悬挂在顶部快捷入口（答题记录/错题本/题库管理）和"检测概览"面板之间，与整体布局格格不入。用户需要将章节检测功能自然地融入"检测概览"面板中，使界面更加统一、简洁。

## What Changes
- 移除独立的"📖 按章节检测"按钮及其展开的章节选择区域（L651-779）
- 在"检测概览"面板顶部新增视图模式切换：**单元视图** | **章节视图**
- 章节视图下，概览面板展示"分类 → 章节 → 单元"三级层级结构，每个章节行附带操作按钮（章节检测/章节复习/更新题库）
- 两个视图共享同一套数据（categories, unitData, chaptersMap），无需额外加载
- 概览面板内部滚动独立，`max-height: 60vh` 保持不变

## Impact
- Affected specs: 单元检测入口页
- Affected code: `src/pages/UnitTestMain.jsx`（主要改动 L651-779 区域，概览面板 L782-969 区域）
- 不影响：答题记录、错题本、题库管理、下方分类卡片区、UnitGroup 组件、删除/移动卡片弹窗

## MODIFIED Requirements

### Requirement: 检测概览面板支持双视图切换
系统 SHALL 在检测概览面板顶部提供"单元视图"和"章节视图"两个 Tab 切换，默认显示"单元视图"。

#### Scenario: 默认显示单元视图
- **WHEN** 用户进入单元检测页面
- **THEN** 检测概览面板默认展示"单元视图"Tab，显示分类→单元两级结构（与当前行为一致）

#### Scenario: 切换到章节视图
- **WHEN** 用户点击"章节视图" Tab
- **THEN** 概览面板切换为"分类→章节→单元"三级结构
- **AND** 每个分类可展开，展示其下的章节列表
- **AND** 每个章节可进一步展开，展示其下的单元列表
- **AND** 每个章节行右侧显示操作按钮区（章节检测/章节复习/更新题库）

#### Scenario: 章节选择与操作
- **WHEN** 用户在章节视图中选中某个章节
- **THEN** 该章节高亮（绿色背景）
- **AND** 显示该章节下的单元列表
- **AND** 章节行右侧出现三个操作按钮：章节检测、章节复习、更新题库
- **AND** 点击按钮触发对应的 handleChapterTest / handleChapterReview / handleChapterUpdateBank

#### Scenario: 无章节的分类
- **WHEN** 某个分类下没有章节
- **THEN** 该分类在章节视图中展开后显示"该分类下暂无章节"提示

#### Scenario: 切换回单元视图
- **WHEN** 用户在章节视图中点击"单元视图" Tab
- **THEN** 概览面板恢复为分类→单元两级结构
- **AND** 章节检测相关状态（selectedChapterId, activeChapterCategoryId）被重置

## REMOVED Requirements

### Requirement: 独立章节检测按钮
**Reason**: 该按钮孤立于页面布局中，与检测概览功能重叠，整合后不再需要
**Migration**: 功能完整迁移至检测概览面板的"章节视图" Tab 中，用户操作路径更短、更直观
