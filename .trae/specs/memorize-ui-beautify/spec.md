# 背诵界面 UI 美化 Spec

## Why
当前背诵界面视觉风格偏基础，分类选择区、提示横幅、筛选下拉框等区域缺乏精致感，不符合现代简约审美。

## What Changes
- 分类选择按钮：从纯色方块升级为带渐变/投影的精致 pill 按钮
- 顶部提示横幅：增加图标、柔和色彩、毛玻璃效果
- 筛选下拉框：圆角胶囊形状 + 投影 + 更佳触控体验
- 整体视觉统一：卡片、进度条、统计区、底部按钮同步微调

## Impact
- Affected specs: memorize-ui-beautify
- Affected code: `src/pages/Memorize.jsx`, `src/index.css`

## ADDED Requirements

### Requirement: 分类选择区现代简约风格
系统 SHALL 将分类选择按钮从纯色方块升级为带渐变背景、微妙投影、圆角胶囊形状的精致按钮。

#### Scenario: 默认状态
- **WHEN** 用户查看分类选择栏
- **THEN** 未选中分类按钮显示为浅色背景 + 细边框 + 圆角胶囊形状，文字颜色柔和

#### Scenario: 选中状态
- **WHEN** 用户点击某个分类
- **THEN** 选中分类按钮显示主色渐变背景 + 白色文字 + 微妙投影 + 轻微缩放动画

#### Scenario: 无分类
- **WHEN** 没有任何分类存在
- **THEN** 显示柔和引导提示文字

### Requirement: 顶部提示横幅美化
系统 SHALL 将复习提醒、到期卡片提示等横幅从纯色矩形升级为带图标、柔和渐变背景、毛玻璃效果的精美通知条。

#### Scenario: 复习提醒（艾宾浩斯/复习模式）
- **WHEN** 用户在艾宾浩斯或复习模式中查看剩余到期卡片
- **THEN** 显示带时钟图标、柔和蓝色渐变背景、圆角边框的提示条

#### Scenario: 到期卡片提示（顺序/活跃模式）
- **WHEN** 用户在顺序或活跃模式中有到期卡片待复习
- **THEN** 显示带警告图标、柔和暖色渐变背景、操作按钮的提示条

### Requirement: 筛选下拉框美化
系统 SHALL 将章节/单元下拉选择器升级为圆角胶囊形状 + 微妙投影 + 更佳触控体验。

#### Scenario: 默认状态
- **WHEN** 用户查看章节/单元下拉框
- **THEN** 显示圆角胶囊形状、浅色背景、细边框的下拉框

#### Scenario: 选中状态
- **WHEN** 用户选择了某个章节或单元
- **THEN** 下拉框边框变为高亮色，文字加粗

### Requirement: 整体视觉统一
系统 SHALL 确保背诵界面所有元素（卡片、进度条、统计区、底部按钮）风格统一，符合现代简约审美。

#### Scenario: 卡片展示
- **WHEN** 用户查看背诵卡片
- **THEN** 卡片带柔和投影、圆角、白色背景，问题/答案标签精致

#### Scenario: 进度条
- **WHEN** 用户查看背诵进度
- **THEN** 进度条带圆角端点、渐变填充色

#### Scenario: 学习统计区
- **WHEN** 用户查看底部统计
- **THEN** 统计区带柔和背景、圆角卡片、数字加粗突出

#### Scenario: 底部操作按钮
- **WHEN** 用户查看底部操作按钮
- **THEN** 按钮带柔和投影、圆角、清晰的状态色区分
