## 测试用例参考

### 艾宾浩斯模式测试
1. 创建新卡片 → 24小时后应出现在艾宾浩斯模式
2. 标记卡片为已掌握 → 1天后应再次出现
3. 再次标记已掌握 → 2天后应再次出现

### 错题本测试
1. 标记卡片为待复习 → 错误记录+1
2. 再次标记为待复习 → 错误记录+1
3. 标记为已掌握 → 错误记录不再增加

### 每日目标测试
1. 设置每日目标为20张
2. 学习5张卡片 → 进度显示5/20 (25%)
3. 学习20张卡片 → 进度显示100%

### 交互动画测试
1. 点击卡片翻转 → 有触觉反馈
2. 左滑卡片 → 操作菜单出现
3. 右滑卡片 → 无反应（仅支持左滑）
