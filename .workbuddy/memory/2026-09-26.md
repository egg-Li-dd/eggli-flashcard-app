### 推送排障（重要经验）
- 症状：push POST 阶段无限挂死（GET ls-remote 偶尔能过）；根因是 system `credential.helper` 链走 GCM，GCM 无凭据交互式挂起，`-c credential.helper=store` 不会覆盖它
- 解法：GitHub App 私钥 → installation token（脚本 `C:/creategame/Github-app/scripts/_get_installation_token_for_git.py`，httpx 新版 `proxy=` 单数；.env 里 INSTALLATION_ID 为空需先 GET /app/installations 解析）→ token 嵌 URL + `-c credential.helper=` 禁所有 helper 直推
- `.env`/`keys/app.private-key.pem` = MCP GitHub App 的完整身份链，可复用于 git 认证
- 已推送：`64844bf..6add5a1 main -> main`（ls-remote 确认远端=6add5a1）
