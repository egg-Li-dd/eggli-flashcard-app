# Vosk 模型下载"正在连接服务器"问题分析与修复方案

## Overview
- **Summary**: 分析并修复 Vosk 离线语音识别模型下载时持续显示"正在连接服务器"的问题，涵盖网络连接诊断、多下载源自动切换、超时优化、用户体验改进等方面
- **Purpose**: 解决用户在国内网络环境下下载 Vosk 模型时连接时间过长或失败的问题，提升下载成功率和用户体验
- **Target Users**: 使用 Vosk 离线语音识别功能的移动端应用用户

## Goals
- 诊断"正在连接服务器"问题的根本原因
- 优化下载连接流程，减少连接等待时间
- 实现下载源自动 fallback 机制
- 增加网络诊断和错误提示功能
- 提升用户下载体验和成功率

## Non-Goals (Out of Scope)
- 不修改 Vosk 语音识别核心功能
- 不引入新的第三方下载库
- 不实现后台下载/通知栏下载
- 不修改应用其他功能模块

## Background & Context

### 问题现象
用户点击下载按钮后，界面持续显示"正在连接服务器..."，长时间无进度更新，切换所有下载源（主源、GitHub、蓝奏云）均出现此问题。

### 当前下载流程
1. 前端点击下载 → 设置 UI 状态为 "正在连接服务器"
2. 原生端发送 `voskDownloadProgress` 事件（stage=downloading, progress=-1）
3. 执行 HTTP GET 连接（10秒超时 × 3次重试 = 最长约 38 秒等待）
4. 连接成功后开始下载并实时更新进度

### 可能的根本原因
1. **网络原因**：国内访问 alphacephei.com 和 GitHub 速度慢或超时
2. **超时设置**：10秒连接超时 × 3次重试 = 最长 38 秒等待
3. **蓝奏云解析**：蓝奏云分享链接解析可能失败或超时
4. **UI 反馈不足**：连接阶段无进度或倒计时提示
5. **断点续传文件**：已有不完整文件可能导致 Range 请求异常
6. **HTTPS 证书问题**：部分设备可能存在 SSL 证书验证问题

## Functional Requirements

- **FR-1**: 下载连接阶段增加实时状态反馈（倒计时、重试次数）
- **FR-2**: 实现多下载源自动 fallback 机制
- **FR-3**: 增加网络连通性预检查功能
- **FR-4**: 优化超时和重试策略（缩短首次等待时间）
- **FR-5**: 增加详细的错误诊断信息和解决建议
- **FR-6**: 断点续传异常自动恢复（损坏文件自动清理）
- **FR-7**: 前端增加连接超时倒计时显示

## Non-Functional Requirements

- **NFR-1**: 首次连接失败应在 15 秒内给出反馈并尝试备用源
- **NFR-2**: 下载源切换用户可感知，状态变化有明确提示
- **NFR-3**: 错误信息包含具体原因和解决建议
- **NFR-4**: 不增加 APK 包大小超过 100KB
- **NFR-5**: 兼容 Android 7.0+（API 24+）

## Constraints

- **Technical**: 基于 Capacitor + Android 原生插件架构，使用 HttpURLConnection
- **Business**: 不引入付费服务，仅使用免费下载源
- **Dependencies**: Vosk Android SDK 0.3.45，无额外依赖

## Assumptions

- 用户设备已连接互联网
- 蓝奏云分享链接在报告生成时有效
- 用户具备基本的网络故障排查能力
- 国内网络环境下境外服务器访问较慢是普遍现象

## Acceptance Criteria

### AC-1: 连接阶段状态反馈增强
- **Given**: 用户点击下载按钮
- **When**: 处于连接服务器阶段
- **Then**: 界面显示连接超时倒计时（如"正在连接服务器...（5s）"）和重试次数提示
- **Verification**: `programmatic`
- **Notes**: 每 1 秒更新倒计时显示

### AC-2: 多下载源自动 fallback
- **Given**: 当前下载源连接失败
- **When**: 达到最大重试次数仍无法连接
- **Then**: 自动切换到下一个可用下载源继续下载，并提示用户已切换
- **Verification**: `programmatic`
- **Notes**: 切换顺序：主源 → GitHub → 蓝奏云 → 失败提示

### AC-3: 网络连通性预检查
- **Given**: 用户点击下载按钮
- **When**: 开始下载前
- **Then**: 快速检查网络连接状态，无网络时立即提示
- **Verification**: `programmatic`
- **Notes**: 使用 ConnectivityManager 检查

### AC-4: 断点续传异常恢复
- **Given**: 已有不完整的下载文件
- **When**: 断点续传失败或文件损坏
- **Then**: 自动删除损坏文件并重新开始下载
- **Verification**: `programmatic`
- **Notes**: Range 请求返回 416 或文件校验失败时触发

### AC-5: 错误诊断信息增强
- **Given**: 下载失败
- **When**: 向用户显示错误信息
- **Then**: 错误信息包含：具体错误类型、可能的原因、建议的解决方法
- **Verification**: `human-judgment`
- **Notes**: 错误类型包括：网络断开、DNS失败、连接超时、服务器错误等

### AC-6: 蓝奏云解析超时保护
- **Given**: 使用蓝奏云下载源
- **When**: 解析分享链接超过 15 秒
- **Then**: 超时后提示解析失败，建议切换其他源
- **Verification**: `programmatic`
- **Notes**: 解析超时独立设置，不影响下载连接超时
