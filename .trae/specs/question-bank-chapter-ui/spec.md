# 题库管理界面章节集成与 UI 美化 Spec

## Why
题库管理界面当前仅支持"分类→单元"两级选择，但在引入章节概念后，分类下已存在章节层级（分类→章节→单元→卡片）。题库管理界面缺少章节层，导致用户无法按章节浏览和管理题目。同时界面使用大量内联样式，缺乏统一的设计语言，需要美化。

## What Changes
- 题库管理界面新增章节选择层：分类 → 章节 → 单元 → 题目，三步选择流程
- 无章节的分类保持原有"分类→单元"两步流程（兼容降级）
- 美化 UI：统一卡片样式、圆角、间距、配色，使用 CSS 变量与项目整体风格一致
- 保留所有现有功能：手动添加题目、编辑、删除、清空、答题预览

## Impact
- Affected specs: 无
- Affected code: `src/pages/QuestionBankPage.jsx`, `src/index.css`
- 不涉及 `testQuestions` 表结构变更（题目仍按 unitId 分组，章节仅用于展示层级）

## ADDED Requirements

### Requirement: 章节选择层
系统 SHALL 在分类选择后，若该分类存在章节，则先展示章节列表供用户选择，再展示该章节下的单元列表。

#### Scenario: 分类有章节
- **WHEN** 用户选择一个有章节的分类
- **THEN** 系统展示该分类下的章节列表，每个章节显示其下单元数和题目总数
- **AND** 用户点击章节后进入该章节下的单元列表
- **AND** 用户可在单元列表页返回章节列表

#### Scenario: 分类无章节
- **WHEN** 用户选择一个无章节的分类
- **THEN** 系统直接展示该分类下的单元列表（保持原有两步流程）
- **AND** 不显示章节选择层

#### Scenario: 章节无单元
- **WHEN** 用户点击一个无单元的章节
- **THEN** 系统展示空状态提示"该章节下暂无单元"

### Requirement: 章节级题目统计
系统 SHALL 在章节列表中展示每个章节的题目总数。

#### Scenario: 章节题目统计
- **WHEN** 章节列表渲染
- **THEN** 每个章节卡片显示该章节下所有单元的题目总数
- **AND** 数字实时反映当前题库状态

### Requirement: UI 美化
系统 SHALL 对题库管理界面进行视觉美化，使用统一的 CSS 类和设计变量。

#### Scenario: 视觉一致性
- **WHEN** 用户进入题库管理页面
- **THEN** 页面使用统一的卡片样式、圆角、间距
- **AND** 分类选择器使用圆角卡片容器
- **AND** 章节/单元卡片有清晰的视觉层次
- **AND** 题目卡片有题型标签、难度标签、知识点标签
- **AND** 按钮使用项目统一的 btn 系统
- **AND** 空状态有友好的图标和提示文字
- **AND** 所有交互元素满足移动端 44px 最小触控高度

## MODIFIED Requirements

### Requirement: 题库管理页面布局
系统 SHALL 重构题库管理页面为三步（或两步）选择流程，层级关系清晰。

#### Scenario: 三步流程（有章节）
- **WHEN** 分类有章节
- **THEN** 步骤1：分类选择 → 步骤2：章节选择 → 步骤3：单元选择 → 题目列表
- **AND** 每步有清晰的标题和返回按钮

#### Scenario: 两步流程（无章节）
- **WHEN** 分类无章节
- **THEN** 步骤1：分类选择 → 步骤2：单元选择 → 题目列表
- **AND** 行为与原有流程一致
