# 背景自定义与界面风格调节 - Verification Checklist

## 功能完整性

- [ ] 「显示与偏好」页面有「背景与风格」入口行，显示当前方案名称
- [ ] 点击入口可正确跳转到背景与风格设置页
- [ ] 背景与风格页面包含：我的方案、预设背景、自定义背景、卡片风格、按钮透明度、恢复默认六个区域

## 我的方案（多套风格方案管理）

- [ ] 页面顶部有「我的方案」区域，横向滚动展示方案卡片
- [ ] 6 个预设主题显示在方案列表前面（不可删除）
- [ ] 已保存的自定义方案显示在预设后面
- [ ] 当前应用的方案有「使用中」高亮标识
- [ ] 点击方案卡片后立即应用该方案
- [ ] 有「保存当前风格」按钮，点击弹出命名输入框
- [ ] 保存成功后方案出现在列表中
- [ ] 方案支持重命名（长按或菜单操作）
- [ ] 方案支持删除（需二次确认）
- [ ] 至少支持保存 10 套自定义方案

## 预设背景主题

- [ ] 6 套预设主题以卡片网格形式展示
- [ ] 每套主题有预览色块和名称
- [ ] 当前选中项有高亮边框标识
- [ ] 点击任一预设，背景和卡片颜色即时切换
- [ ] 6 套主题分别为：默认浅色、默认深色、护眼米色、清新蓝调、柔和紫霞、极简灰白

## 自定义背景图片

- [ ] Web 端：有「选择图片」按钮可打开文件选择器
- [ ] 移动端：有「选择图片」按钮，点击弹出底部菜单（拍照/从相册/取消）
- [ ] 选择图片后背景立即显示
- [ ] 图片显示模式：填充 / 适应 / 平铺 / 居中 四种可选
- [ ] 背景模糊度滑块：0-20px 可调
- [ ] 背景遮罩透明度滑块：0%-60% 可调
- [ ] 有「清除背景」按钮可恢复预设背景
- [ ] 图片存储后刷新页面仍然有效

## 卡片风格调节

- [ ] 卡片圆角滑块：0-24px，步长 2px
- [ ] 卡片阴影：无/轻微/中等/明显 四档
- [ ] 卡片边框：无/细线/粗线 三档
- [ ] 卡片透明度滑块：70%-100%，步长 5%
- [ ] 有实时预览卡片展示效果
- [ ] 滑块拖动时即时更新

## 按钮透明度调节

- [ ] 主按钮透明度滑块：80%-100%，步长 5%
- [ ] 次按钮透明度滑块：70%-100%，步长 5%
- [ ] 有实时预览按钮展示效果
- [ ] 滑块拖动时即时更新

## 一键恢复默认

- [ ] 页面底部有「恢复默认设置」按钮
- [ ] 点击后弹出确认对话框（二次确认）
- [ ] 确认后所有当前设置恢复默认值
- [ ] 恢复后显示 Toast 提示
- [ ] 恢复默认不删除已保存的风格方案

## 数据持久化

- [ ] 所有设置修改后自动保存到 localStorage
- [ ] 刷新页面后设置保持不变
- [ ] 关闭并重新打开应用后设置保持不变
- [ ] 已保存的风格方案持久化存储

## 兼容性

- [ ] 与浅色主题兼容（文字清晰可读）
- [ ] 与深色主题兼容（文字清晰可读）
- [ ] 与自动主题切换兼容
- [ ] 与护眼模式兼容
- [ ] 不影响其他功能（背诵、出题、分类等）
- [ ] 支持 prefers-reduced-motion（无多余动画）

## 移动端适配

- [ ] 所有按钮最小可点击区域 44x44px
- [ ] 375px 宽度下布局正常，无横向溢出
- [ ] 滑块控件易于触摸操作
- [ ] 文字完整显示，不被截断
- [ ] 符合移动端 App 界面标准
- [ ] 移动端拍照功能正常（Android）
- [ ] 移动端相册选图功能正常（Android）

## 性能

- [ ] 设置切换即时生效（无明显延迟）
- [ ] 背景图片不影响页面滚动流畅度
- [ ] 60fps 流畅度保持
- [ ] 风格方案切换响应 < 200ms
- [ ] 构建成功，无报错
