## 边界情况检查

- [ ] 临时知识点为空数组 → 正常返回空结果
- [ ] 现有知识点为空数组 → 返回所有临时知识点
- [ ] 临时知识点=1 → 单个知识点处理正确
- [ ] 现有知识点=1 → 比对正确
- [ ] 知识点评分全部 < 阈值 → 无重复被过滤
- [ ] 知识点评分全部 > 阈值 → 全部被标记重复

## 端到端测试

- [ ] 重复输入相同的40个知识点 → 应全部被识别为重复（或大部分）
- [ ] 部分重复测试：40个知识点中有10个与现有重复 → 应检测出10个重复
- [ ] 空现有知识点 → 去重后知识点数量不变
- [ ] 大批量测试：输入100个知识点，现有200个 → 分批处理正确
