
# 移动端数据迁移失败修复计划

## 一、问题分析

用户反馈数据迁移在网页上正常工作，但在 Android APK 上无法上传。经过代码分析，可能的原因包括：

### 1. 网络层问题
- **Capacitor Android 网络配置**：移动端可能存在 CORS、SSL 或代理问题
- **cleartext 配置**：虽然已设置 `cleartext: true`，但可能仍有网络限制

### 2. Supabase 客户端配置
- **Session 检测**：移动端禁用了 URL session 检测（`detectSessionInUrl: !isCapacitor()`），但可能影响其他功能
- **缓存问题**：Supabase 客户端缓存可能导致移动端使用过期配置

### 3. 错误处理不足
- 当前代码错误信息不够详细，用户无法知道具体失败原因
- 缺少移动端特定的错误捕获和日志记录

### 4. IndexedDB 访问
- 移动端 IndexedDB 可能有存储空间限制或访问权限问题

## 二、修复方案

### 方案 1：增强错误处理和用户反馈
- 在 `migrate.js` 中添加更详细的错误日志
- 在 `Account.jsx` 中显示具体的错误信息，帮助用户诊断问题

### 方案 2：优化移动端网络配置
- 确保 Capacitor 配置正确处理 HTTPS 请求
- 添加网络连接状态检测

### 方案 3：改进迁移流程
- 添加数据验证步骤
- 添加进度回调的详细信息
