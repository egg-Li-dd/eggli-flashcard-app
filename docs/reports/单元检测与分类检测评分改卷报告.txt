3.1 单选题评分（single_choice）

评分逻辑：
  1. 获取用户选择的 selectedIndex（0-based）
  2. 从 question.options 中取出对应选项的 label（如 "A"、"B"）
  3. 与 question.answer 做精确匹配
  4. 备选：selectedText 也做匹配

判定：label === answer  → 正确，否则 → 错误

3.2 多选题评分（multi_choice）

评分逻辑：
  1. 获取用户选择的 selectedIndices 数组
  2. 将每个 index 映射为 option.label（转大写）
  3. 过滤出合法的 A-Z 字母，排序后拼成字符串（如 "ABD"）
  4. 将 question.answer 同样归一化为纯字母+排序格式
  5. 与用户答案做精确匹配

判定：答案完全一致 → 正确，否则 → 错误
注意：多选题必须全对才得分，无部分给分

3.3 填空题评分（fill_blank）

评分逻辑：
  1. 获取用户输入的 answerText（trim 后）
  2. 与 question.answer 做不区分大小写的精确匹配

判定：answerText.toLowerCase() === answer.toLowerCase() → 正确
注意：是精确匹配，不支持近义词或编辑距离容忍

3.4 判断题评分（true_false / judge）

评分逻辑：
  1. 获取用户答案（可能是 boolean 或 string）
  2. 转换为布尔值（true/正确/对 → true）
  3. 将正确答案也转换为布尔值
  4. 比较两个布尔值

判定：userBool === correctBool → 正确
支持的答案格式：true/false、正确/错误、对/错

4.1 分数计算公式

  正确题数 = gradingResults 中 isCorrect === true 的数量
  总题数   = 题目总数
  得分     = Math.round((正确题数 / 总题数) × 100)
  
  结果以百分比形式展示，如：
    答对 8/10 题 → 80分

4.2 结果数据结构

{
  mode,              // 'unit' | 'category' | 'review' | 'wrong'
  unitId,            // 单元ID
  categoryId,        // 分类ID
  totalQuestions,    // 总题数
  totalCorrect,      // 正确题数
  score,             // 得分（0-100）
  elapsed,           // 用时（秒）
  graded,            // 逐题评分结果数组
  finishedAt,        // 完成时间（ISO 8601）
}

graded 中每项的结构：
{
  questionId,        // 题目ID
  cardId,            // 关联卡片ID
  stem,              // 题干
  type,              // 题型
  userAnswer,        // 用户答案（null 表示未作答）
  correctAnswer,     // 正确答案
  isCorrect,         // 是否答对
  analysis,          // 解析
  knowledgePoint,    // 知识点
  difficulty,        // 难度
}

如果用户没有回答某道题就提交：
  · userAnswer = null
  · isCorrect = false
  · 该题计入总数，视为错误

9.1 概述

gradeTest() 函数是完整的增强评分流程，包含 AI 评分、难度加权、
薄弱点分析、题型统计、掌握程度联动等功能。
由 UnitTestPage.jsx 的 handleSubmitAll() 在有 AI 配置时调用。

9.2 增强评分流程（9步）

  第1步：本地客观题评分
    · 单选题：同 checkAnswer，选出 option.label 匹配
    · 多选题：支持部分给分
      公式：max(0, 正确选中数 - 多选惩罚×0.5) / 正确选项总数
      得分范围 0~1，score >= 1.0 才算正确
    · 判断题：同 checkAnswer

  第2步：填空题/简答题 → AI 评分（可选）
    · 填空题：调用 AI 判断语义是否正确（降级为编辑距离≥0.8）
    · 简答题：调用 AI 判断语义相似度（降级为关键词匹配）
    · AI 不可用时自动降级为本地评分

  第3步：AI 答案解析生成（异步）
    · 为缺少解析的题目调用 AI 生成简短解析

  第4步：计算加权分数
    · 难度权重：easy×1.0, medium×1.5, hard×2.0
    · 加权得分 = Σ(每题得分 × 难度权重)
    · 最大可能得分 = Σ(难度权重)

  第5步：计算简单统计
    · 正确率 = 答对数 / 总数 × 100%
    · 总得分 = 正确的题数

  第6步：薄弱知识点分析
    · 统计每道错题的知识点
    · 按错误频率排序，取 TOP5

  第7步：题型统计
    · 按题型分组（单选/多选/判断/填空/简答）
    · 计算各题型的正确率

  第7.5步：AI 整体评价（仅强模型，异步）
    · 将所有题目、用户答案、正确率发送给 AI
    · AI 生成综合评价：整体评价、优点列表、不足列表、学习建议、重点复习项
    · 仅 DeepSeek/火山引擎/阿里云百炼 适用（讯飞 Spark Lite 不适用）
    · 超时 20000ms，失败时 holisticEvaluation = null，不影响主流程

  第8步：保存测试记录
    · 写入 testRecords 表

  第9步：更新掌握程度与错题
    · 逐题：答对→setCardStatus('mastered') + clearWrongAnswer
           答错→setCardStatus('review') + addWrongAnswer
    · 全局：accuracy ≥ 90% → 全部 mastered + 清空错题
            accuracy ≥ 60% → 全部 learning
            accuracy < 60% → 全部 review

9.4 强/弱模型调用路径分离

  强模型路径（callAiForGradingStrong）：
    · 适用：DeepSeek、火山引擎 Doubao、阿里云百炼 Qwen
    · 特点：统一 prompt、一次性批量评分、较大 max_tokens
    · 超时：15000ms

  弱模型路径（callAiForGradingWeak）：
    · 适用：讯飞 Spark Lite
    · 特点：简化 prompt、分批处理（每批≤4题）、索引映射
    · 降级：批次解析失败时跳过该批次，不影响其他批次
    · 超时：15000ms/批

  解析生成同样分离：
    · sendAiRequestStrong（强模型）
    · sendAiRequestWeak（弱模型，简化 prompt + 容错）

9.5 手动修正评分（manualOverrideGrading）

  在 UnitTestResult.jsx 中支持：
  · 用户点击"标记为正确"或"标记为错误"
  · 修改 gradingResult 的 isCorrect、score、gradedBy
  · 调用 recalculateScore() 重新计算总分和加权分
  · 标记为 'manual' 以示区分

9.6 AI 整体评价（仅强模型）

  触发条件：使用 DeepSeek/火山引擎/阿里云百炼 时自动调用
  不适用：讯飞 Spark Lite（弱模型不支持）

  调用时机：第7.5步（题型统计之后，保存记录之前，异步执行）

  prompt 构建内容：
    · 基本信息：总题数、答对数、正确率、整体评价
    · 逐题详情：题型、难度、题干、用户答案、正确答案、本题结果
    · 用户答案处理：
        - 单选/多选：selectedIndices → 选项 label
        - 判断：answer 布尔值
        - 填空/简答：answerText

  AI 返回 JSON：
  {
    "overallComment": "整体评价（50字以内）",
    "strengths": ["优点1", "优点2", "优点3"],
    "weaknesses": ["不足1", "不足2", "不足3"],
    "studySuggestions": ["建议1", "建议2", "建议3"],
    "keyPointsToReview": ["重点复习1", "重点复习2"]
  }

  gradeTest 返回值新增：
    holisticEvaluation: Promise（异步，失败时为 null）

11.1 当前评分机制

  1. 双模式自动切换：无 AI 配置 → 简易模式，有 AI 配置 → 增强模式
  2. 简易模式：全本地精确匹配，无需网络，即时出分
  3. 增强模式：AI 语义评分（填空/简答）+ 难度加权 + 薄弱点分析
     + 题型统计 + AI 整体评价
  4. 强/弱模型路径分离：DeepSeek/火山/百炼走强模型路径，
     讯飞 Spark Lite 走弱模型路径（简化 prompt + 分批处理）
  5. 增强模式自动保存：错题记录、答题记录、掌握程度均由 gradeTest 内部处理
  6. 结果页增强展示：加权分、题型统计、薄弱知识点 TOP5
  7. AI 整体评价（仅强模型）：综合评价整份试卷，生成优缺点、学习建议
