# Vosk 模型下载连接问题修复 - 验证清单

## 连接状态反馈

- [x] 连接阶段每秒发送一次进度事件
- [x] 事件包含 countdown 字段（剩余秒数）
- [x] 事件包含 retryCount 字段（当前重试次数）
- [x] 事件包含 maxRetries 字段（最大重试次数）
- [x] 前端 UI 显示倒计时和重试状态
- [x] 倒计时数字变化流畅（每秒更新）

## 多下载源自动 fallback

- [x] 原生端支持传入多个下载 URL 数组
- [x] 第一个源失败后自动切换到下一个
- [x] 切换时发送 sourceChanged 事件
- [x] 事件包含 fromSource（上一个源）
- [x] 事件包含 toSource（下一个源）
- [x] 前端显示切换提示
- [x] 所有源都失败后才返回最终错误
- [x] 切换顺序正确：主源 → GitHub → 蓝奏云

## 网络连通性预检查

- [x] 下载前检查网络连接状态
- [x] 无网络时立即返回错误（不进入下载流程）
- [x] 错误信息包含"请检查网络连接"建议
- [ ] 飞行模式下正确检测无网络
- [ ] Wi-Fi 和移动网络均可正常下载
- [x] 不额外要求 ACCESS_NETWORK_STATE 以外的权限

## 断点续传异常恢复

- [x] Range 请求返回 416 时自动删除旧文件
- [x] 删除后重新开始完整下载
- [x] 文件大小大于预期时自动清理
- [x] 用户看到 "检测到不完整文件，重新开始下载" 提示
- [ ] 重新下载后的文件可以正常解压和使用

## 错误诊断信息

- [x] 不同错误类型返回不同的 errorCode
- [x] 错误类型至少包括：network_disconnected, dns_failed, connection_timeout, server_error, lanzou_parse_failed
- [x] 每个错误包含 suggestion 字段（解决建议）
- [x] 前端错误显示包含原因和建议两部分
- [x] 错误信息友好易懂，避免技术术语
- [x] 蓝奏云解析失败有单独的错误码和建议

## 蓝奏云解析超时保护

- [x] 蓝奏云解析有独立的 15 秒超时
- [x] 超时时返回 lanzou_parse_timeout 错误码
- [x] 错误信息包含"蓝奏云解析超时"字样
- [x] 错误建议包含"可切换到其他下载源"提示
- [x] 解析阶段也有状态反馈

## 综合测试

- [ ] 断网环境下下载：立即提示无网络
- [ ] 慢速网络环境：有倒计时和进度反馈
- [ ] 主源不可达：自动切换到 GitHub
- [ ] GitHub 不可达：自动切换到蓝奏云
- [ ] 蓝奏云解析失败：明确错误提示和建议
- [ ] 所有源都失败：显示综合错误信息
- [ ] 下载中断后重新下载：支持断点续传
- [ ] 损坏的临时文件：自动清理并重新下载
- [ ] 取消下载：状态正确重置
- [x] 重复点击下载：不会重复启动（状态锁生效）
