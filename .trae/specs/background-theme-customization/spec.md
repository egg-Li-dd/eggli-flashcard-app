# 背景自定义与界面风格调节 - Product Requirement Document

## Overview
- **Summary**: 在「显示与偏好」设置中新增「背景与风格」子页面，允许用户自定义应用背景（预设主题+自定义图片）、卡片视觉风格、按钮透明度等界面元素，支持保存多套风格方案，提升个性化体验。
- **Purpose**: 让用户可以根据个人喜好定制应用外观，支持多套风格方案快速切换，增强产品的个性化体验和用户粘性。
- **Target Users**: 所有应用用户，尤其是对界面美观度和个性化有要求的用户。

## Goals
- 用户可从 6 套预设背景主题中选择
- 用户可上传自定义背景图片并应用（支持本地文件 + 移动端拍照/相册）
- 用户可调节卡片风格（圆角大小、阴影强度、边框样式、透明度）
- 用户可调节按钮透明度
- 所有设置实时预览、即时生效
- 支持保存多套自定义风格方案，可命名、切换、删除
- 设置数据持久化存储，重启后保持
- 与现有主题模式（浅色/深色/自动）兼容
- 不影响移动端 App 功能和性能

## Non-Goals (Out of Scope)
- 不提供自定义 CSS 编辑功能
- 不提供字体更换功能（已有字号调节）
- 不提供图标包更换
- 不涉及 AI 生成背景图片
- 不支持动态视频背景
- 不支持云端同步风格方案（仅本地存储）

## Background & Context
- 当前应用已有显示设置页面 `SettingsDisplay.jsx`，包含字号、护眼模式、主题模式、输入栏模式
- 当前主题系统通过 CSS 变量和 `data-theme` 属性控制（浅色/深色/自动）
- 设置通过 `AppContext.jsx` 全局管理，使用 localStorage 持久化
- 卡片组件使用 `.card`、`.card-flip-container` 等类，按钮使用 `.btn` 类
- 背景色通过 `--color-bg`、`--color-surface` 等 CSS 变量控制
- 移动端基于 Capacitor，可调用原生相机/相册

## Functional Requirements

### FR-1: 背景与风格设置入口
- 在「显示与偏好」页面新增「背景与风格」入口行
- 点击进入新的二级设置页面
- 入口显示当前应用的风格方案名称

### FR-2: 预设背景主题选择
- 提供 6 套预设背景主题：
  - 默认浅色（当前样式）
  - 默认深色（当前暗夜模式）
  - 护眼米色（暖色背景）
  - 清新蓝调（浅蓝渐变）
  - 柔和紫霞（浅紫渐变）
  - 极简灰白（高对比度）
- 每套主题包含：背景色/渐变、卡片背景色、主色调适配
- 主题选项以卡片形式展示，可预览效果
- 点击即应用，即时生效

### FR-3: 自定义背景图片
- **Web 端**：支持从本地文件选择图片作为背景
- **移动端**：支持拍照和从相册选择图片（Capacitor Camera API）
- 支持图片显示模式：填充、适应、平铺、居中
- 支持背景模糊度调节（0-20px）
- 支持背景遮罩透明度调节（保证文字可读性）
- 图片存储在 localStorage（base64）
- 可一键清除自定义背景，恢复为预设背景

### FR-4: 卡片风格调节
- 卡片圆角调节：0px - 24px，滑块控制
- 卡片阴影强度：无 / 轻微 / 中等 / 明显，四档选择
- 卡片边框样式：无 / 细线 / 粗线，三档选择
- 卡片透明度调节：70% - 100%，滑块控制
- 实时预览卡片效果

### FR-5: 按钮透明度调节
- 主按钮透明度：80% - 100%，滑块控制
- 次按钮/幽灵按钮透明度：70% - 100%，滑块控制
- 实时预览按钮效果

### FR-6: 实时预览
- 所有调节项都有实时预览区域
- 预览区域展示：标题文字、卡片样式、按钮样式
- 调节时即时更新预览效果

### FR-7: 多套风格方案管理
- 支持保存当前设置为一个风格方案（需输入名称）
- 风格方案列表展示，可点击切换应用
- 支持重命名风格方案
- 支持删除风格方案（需二次确认）
- 当前应用的方案有高亮标识
- 至少支持保存 10 套自定义方案

### FR-8: 一键重置
- 提供「恢复默认」按钮
- 点击后所有背景与风格设置恢复为默认值
- 需二次确认防止误操作

## Non-Functional Requirements

### NFR-1: 性能
- 所有 CSS 变量修改应在 1 帧（16ms）内生效
- 背景图片不应导致页面滚动卡顿（目标 60fps）
- 设置切换动画流畅，无明显闪烁
- 风格方案切换响应时间 < 200ms

### NFR-2: 兼容性
- 与现有主题模式（浅色/深色/自动）完全兼容
- 与护眼模式兼容
- 移动端 App 功能不受影响
- 支持 `prefers-reduced-motion` 无障碍设置
- Web 端和移动端功能表现一致（除拍照/相册外）

### NFR-3: 数据持久化
- 所有设置通过 localStorage 持久化
- 风格方案数据结构清晰，便于后续扩展
- 刷新页面、重启应用后保持设置
- 单张背景图片 base64 不影响存储性能

### NFR-4: 移动端适配
- 所有控件在手机屏幕上可点击（最小 44x44px）
- 布局自适应不同屏幕尺寸
- 符合移动端 App 界面标准
- 拍照和相册选择在 Android 端正常工作

## Constraints
- **技术**: React + Vite + 纯 CSS 变量实现，不引入新的第三方样式库
- **存储**: 使用 localStorage 存储设置、背景图片（base64）和风格方案
- **兼容**: 必须与现有主题系统、护眼模式兼容
- **性能**: 60fps 流畅度优先，避免过度渲染
- **移动端**: 使用 Capacitor Camera API 实现拍照/相册

## Assumptions
- 背景图片尺寸用户自行控制，不做硬性大小限制
- 用户理解自定义背景可能影响文字可读性
- 预设主题数量可后续扩展
- 所有设置仅影响前端展示，不涉及后端数据
- 风格方案仅本地存储，不同步到云端

## Acceptance Criteria

### AC-1: 背景与风格入口可用
- **Given**: 用户在「显示与偏好」页面
- **When**: 用户查看页面内容
- **Then**: 可以看到「背景与风格」入口行，显示当前风格方案名称
- **Verification**: `human-judgment`

### AC-2: 预设背景主题选择
- **Given**: 用户在「背景与风格」页面
- **When**: 用户点击任一预设主题卡片
- **Then**: 应用背景立即切换为对应主题，所有页面背景随之改变
- **Verification**: `human-judgment`

### AC-3: 自定义背景图片（Web）
- **Given**: 用户在 Web 端「背景与风格」页面
- **When**: 用户选择一张本地图片作为背景
- **Then**: 背景图片立即生效，文字保持可读
- **Verification**: `human-judgment`

### AC-3b: 自定义背景图片（移动端拍照/相册）
- **Given**: 用户在移动端 App「背景与风格」页面
- **When**: 用户点击「选择图片」并选择拍照或从相册选择
- **Then**: 图片成功获取并应用为背景
- **Verification**: `human-judgment`

### AC-4: 卡片风格调节
- **Given**: 用户在「背景与风格」页面
- **When**: 用户调节卡片圆角/阴影/边框/透明度滑块
- **Then**: 预览卡片和全局卡片样式即时更新
- **Verification**: `human-judgment`

### AC-5: 按钮透明度调节
- **Given**: 用户在「背景与风格」页面
- **When**: 用户调节按钮透明度滑块
- **Then**: 预览按钮和全局按钮透明度即时更新
- **Verification**: `human-judgment`

### AC-6: 设置持久化
- **Given**: 用户已修改背景与风格设置
- **When**: 用户刷新页面或重新打开应用
- **Then**: 设置保持不变，与修改后一致
- **Verification**: `programmatic`

### AC-7: 与现有主题兼容
- **Given**: 用户设置了自定义背景风格
- **When**: 用户切换浅色/深色/自动主题模式
- **Then**: 自定义风格在对应模式下正确适配
- **Verification**: `human-judgment`

### AC-8: 一键恢复默认
- **Given**: 用户已修改多项风格设置
- **When**: 用户点击「恢复默认」并确认
- **Then**: 所有背景与风格设置恢复为初始默认值
- **Verification**: `programmatic`

### AC-9: 移动端适配
- **Given**: 在手机屏幕尺寸下
- **When**: 显示「背景与风格」页面
- **Then**: 所有按钮、控件可点击，布局不溢出，文字完整显示
- **Verification**: `human-judgment`

### AC-10: 不影响其他功能
- **Given**: 背景风格已自定义
- **When**: 使用其他功能（背诵、出题、分类等）
- **Then**: 功能正常，仅视觉风格变化，不影响功能逻辑
- **Verification**: `programmatic`

### AC-11: 保存风格方案
- **Given**: 用户已调节好一组风格设置
- **When**: 用户点击「保存为方案」并输入名称确认
- **Then**: 方案保存成功，出现在方案列表中
- **Verification**: `programmatic`

### AC-12: 切换风格方案
- **Given**: 用户已保存多个风格方案
- **When**: 用户点击任一已保存的方案
- **Then**: 所有风格设置立即切换为该方案的配置
- **Verification**: `human-judgment`

### AC-13: 管理风格方案
- **Given**: 用户已保存多个风格方案
- **When**: 用户进行重命名或删除操作
- **Then**: 操作成功，方案列表正确更新
- **Verification**: `programmatic`
