1功能概览

错题本是 AI 学习辅助应用的核心功能之一，负责收集用户在各类检测中答错的题目，帮助用户针对性复习和巩固薄弱知识点。

🔄

支持云端数据同步（wrong_answers 表），在多设备间保持错题记录一致。
🧠

3完整业务流程

从用户开始答题到错题被收集、展示、重做的完整闭环流程图。

1
进入单元检测
用户在 UnitTestMain 点击单元 → 跳转 UnitTestPage (mode=unit/category/wrong)
↓
2
答题过程
用户逐题作答单选/多选/判断/填空/简答题 → 本地即时反馈或等待提交
↓
3
提交全部答案
点击"提交" → 触发 gradeTest() 函数 / 本地评分逻辑
↓
4
AI / 本地评分判定
客观题本地100%准确评分 · 主观题调用 AI (讯飞/DeepSeek) 或降级为关键词匹配
↓
5
写入错题记录
调用 addWrongAnswer(cardId, categoryId, questionType, {...}) → wrongAnswers 表新增或更新 count+1
↓
6
更新卡片掌握状态
同步调用 setCardStatus() → 将答错卡片标记为"待复习"；答对标记为"已掌握"
↓
7
进入错题本查看
点击"我的错题本" → WrongQuestionsPage 通过 getAllWrongAnswers() 加载全部错题
↓
8
三层分组展示
buildTree() 构建 分类→章节→单元 三级结构，按错题数降序排列
↓
9
错题重做
点击"错题重做" → 跳转 UnitTestPage?mode=wrong&categoryId=xxx 开始专项训练
↓
10
闭环更新
重做后答对 → clearWrongAnswer() 清除错题记录；答错 → count 继续累加并更新 lastWrongAt
💡 设计亮点
错题记录与卡片掌握状态 同步更新，同时在 Memorize 模块的 weak 模式可以直接基于错题表筛选出薄弱卡片进行背诵复习，实现"检测 → 错题 → 背诵复习"的完整学习闭环。

4数据库设计

localStorage (IndexedDB via Dexie) 的 wrongAnswers 表字段结构，以及云端同步的对应表 wrong_answers。

📋 wrongAnswers 表字段清单

字段名 类型 说明
idstring (PK)主键，由 generateId() 生成的唯一 ID
cardIdstring关联的卡片 ID（可为空，独立题目用 questionId 替代）
categoryIdstring所属分类 ID，用于按分类聚合展示
unitIdstring所属单元 ID（v5 新增），用于按单元筛选
chapterIdstring所属章节 ID（v7 新增），支持章节维度查询
questionIdstring题目 ID（cardId 为空时用此字段）
questionTypestring题目类型：single_choice / multi_choice / true_false / fill_blank / short_answer
countnumber累计错误次数，同一张卡/题目重复答错时累加
lastWrongAttimestamp最后一次错误的时间戳，用于排序展示
stemstring题目的题干文本，便于在错题本直接预览
categoryNamestring分类名冗余字段，避免关联查询
unitNamestring单元名冗余字段
updatedAttimestamp记录更新时间戳

🔍 复合索引设计

索引 用途 相关查询
[categoryId + unitId]复合索引getWrongAnswersByCategoryAndUnit() 按分类+单元快速筛选
[categoryId + chapterId]复合索引getWrongAnswersByChapter() 按章节维度查询
lastWrongAt排序索引getAllWrongAnswers() 按最后错误时间倒序
cardId + categoryId复合去重addWrongAnswer() 时判断是否已有记录，有则 count+1

5核心功能模块 (db.js)

以下是 src/services/db.js 中负责错题本功能的 12 个核心数据库操作函数。

➕
addWrongAnswer()
新增或更新错题记录。智能去重：同 cardId+categoryId+unitId 组合已存在时，自动 count+1 并更新 lastWrongAt。
addWrongAnswer(cardId, categoryId, questionType, {unitId, chapterId, stem, questionId})
📥
getAllWrongAnswers()
获取全部错题记录，按 lastWrongAt 倒序排列。为 WrongQuestionsPage 的主数据源。
db.wrongAnswers.orderBy('lastWrongAt').reverse()
🏷️
getWrongAnswersByCategory()
按分类 ID 筛选错题，支持 limit 参数限制返回数量（默认 20 条）。
.where('categoryId').equals(id)
📚
getWrongAnswersByUnit()
按单元 ID 筛选错题，v5 升级后支持以单元维度进行专项训练。
.where('unitId').equals(id)
📖
getWrongAnswersByChapter()
按章节 ID 筛选错题，v7 章节化支持新增的章节维度。
.where('chapterId').equals(id)
🔗
getWrongAnswersByCategoryAndUnit()
按分类+单元组合筛选，使用 [categoryId+unitId] 复合索引保证查询性能。
.where(['categoryId','unitId']).equals([cat, unit])
🔎
getWrongAnswer()
查询单张卡片在指定分类下的错题记录，用于细粒度控制。
.where({cardId, categoryId}).first()
🗑️
clearWrongAnswer()
答对后清除该卡片在指定分类/单元下的错题记录，支持按单元精细化清除。
clearWrongAnswer(cardId, categoryId, unitId)
❌
deleteWrongAnswer()
删除单条错题记录，用户在 UI 上点击单条删除按钮时调用。
db.wrongAnswers.delete(id)
🧹
clearAllWrongAnswers()
清空全部错题记录。用于用户重置学习数据或一键清空。
db.wrongAnswers.clear()
📤
uploadTable('wrong_answers')
sync.js 中调用云端同步，将本地 wrongAnswers 数据上传至云端，支持多设备间同步。
upsert by id
🔄
级联删除/迁移
删除分类时级联删除对应错题；卡片移动分类时同步更新错题表的 categoryId 字段。
deleteCategory / moveCards

7技术亮点与设计优势

错题本功能在架构设计和实现细节上的多个优秀实践。

三层复合索引优化
设计 [categoryId+unitId] 和 [categoryId+chapterId] 复合索引，避免全表扫描，支持分类/章节/单元三维度快速查询，随着数据量增长依然保持性能。
智能去重与累加计数
addWrongAnswer() 写入时先按 (cardId, categoryId, unitId) 查询，已存在则 count+1 更新 lastWrongAt，不存在才新增记录。避免同一题重复产生多条记录。
冗余字段设计
存储 categoryName / unitName / stem 等冗余字段，展示时无需二次 JOIN 查询，前端加载速度更快（典型的"读优化"设计）。
AI / 本地双通道评分
testGradingService.js 支持强模型(DeepSeek/火山引擎/百炼)和弱模型(讯飞 Lite)双通道，主观题答题失败时自动降级为本地关键词匹配 + 编辑距离评分，保证可用性。
掌握程度双向联动
写入错题的同时联动调用 setCardStatus() 更新卡片掌握状态（mastered/review），实现"错题本"与"背诵复习"两大模块的数据打通。
weak 模式薄弱卡片复习
Memorize.jsx 的 weak 模式直接基于 wrongAnswers 表筛选薄弱卡片，形成"检测→错题→背诵"的完整闭环学习路径。
移动端自适应 UI
WrongQuestionsPage 采用 flex 布局 + 三层可折叠卡片，头部统计卡片居中展示，符合手机端单手操作习惯，按钮最小高度 44px 确保可点中。
云端数据一致性
sync.js 的 uploadTable/downloadTable 机制支持本地 IndexedDB 与云端 PostgreSQL wrong_answers 表双向同步，保证多设备错题记录一致。
章节化演进支持
从 v1 单表 → v5 增加 unitId → v7 增加 chapterId，通过数据库版本迁移机制逐步增强，保持向后兼容，体现了良好的迭代演进能力。
级联清理与数据完整性
删除分类/单元时自动清理关联的错题记录；卡片移动分类时同步更新错题表的归属字段，确保数据引用始终有效。
🎯 总结
错题本功能以 WrongQuestionsPage.jsx 为展示核心，以 db.js 的 12+ 个操作函数 为数据基础，以 testGradingService.js 的 AI 双通道评分 为写入源头， 以 UnitTestPage (mode=wrong) 为重做闭环，最终通过 sync.js 云端同步 实现跨设备一致。 整体形成"检测 → 评分 → 写入错题 → 展示 → 重做 → 清除"的完整学习反馈闭环，为用户提供高效的薄弱知识强化途径。
